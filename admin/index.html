The public archive reads data/matches.json. To make a change visible online, publish it here or export the file and commit it yourself.

1 · Export

Download the JSON, then copy it into data/matches.json and commit. Works without any GitHub setup.

2 · Publish directly

Paste a GitHub token with Contents: write on this repo. It is kept in memory for this session only — never saved to disk, never in the page source.
